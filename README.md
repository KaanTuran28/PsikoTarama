## English

PsikoTarama is a modern, fully client-side web app that profiles the intensity of psychological symptoms across six clinical sub-dimensions. It is designed around clinical-psychology principles and modern UX/UI standards, with a dark theme.

### ⚠️ Disclaimer

**This app does not make a medical or psychiatric diagnosis.** The results are not a diagnosis — only a symptom-intensity profile across clinical sub-dimensions. A psychiatrist or clinical psychologist is required for an actual diagnosis and treatment. The developer is not responsible for any consequences of using the app.

### Features

- **Multi-dimensional analysis:** 30 questions measuring six core clinical dimensions:
  - Depressive symptoms (DEP)
  - Anxiety (ANX)
  - Obsessive-compulsive tendencies (OCD)
  - Somatization (SOM)
  - Burnout and stress (STR)
  - Social isolation (SOS)
- **Fully private (zero-backend):** no database or server. Everything is processed in the browser and gone when the page is closed.
- **Modern UX/UI:** smooth animations, an easy-on-the-eyes dark theme and a progress bar.
- **Responsive:** works on all devices.

### Tech stack

- HTML5 (semantic, accessible)
- CSS3 (custom properties, Flexbox, transitions — no framework)
- JavaScript (ES6+) — pure logic and DOM manipulation, no React/Vue

### Running

No server or build tool required — open it directly in a browser.

```bash
git clone https://github.com/KaanTuran28/PsikoTarama.git
cd PsikoTarama
# open index.html in a browser
```

## Türkçe

PsikoTarama, bireylerin psikolojik semptom yoğunluklarını 6 farklı klinik alt boyutta analiz eden, tamamen istemci tarafında (client-side) çalışan modern bir web uygulamasıdır. Klinik psikoloji prensipleri ve modern UX/UI standartları gözetilerek karanlık tema ile tasarlanmıştır.

### ⚠️ Yasal Uyarı ve Etik Beyan

**Bu uygulama tıbbi veya psikiyatrik bir tanı koymaz.** Çıkan sonuçlar "tanı" değil, yalnızca klinik alt boyutlardaki belirti yoğunluğu profilidir. Kesin tanı ve tedavi için bir psikiyatrist veya klinik psikolog muayenesi şarttır. Geliştirici, uygulamanın kullanımından doğabilecek sonuçlardan sorumlu tutulamaz.

### Özellikler

- **Çok boyutlu analiz:** 30 soru ile 6 temel klinik boyutu ölçer:
  - Depresif Belirtiler (DEP)
  - Anksiyete (Kaygı) (ANX)
  - Obsesif-Kompulsif Eğilimler (OKB)
  - Somatizasyon (SOM)
  - Tükenmişlik ve Stres (STR)
  - Sosyal İzolasyon (SOS)
- **Tamamen gizli (zero-backend):** veritabanı veya sunucu bağlantısı yoktur. Tüm veriler tarayıcıda anlık işlenir ve sayfa kapandığında yok olur.
- **Modern UX/UI:** pürüzsüz animasyonlar, göz yormayan karanlık tema ve ilerleme çubuğu.
- **Mobil uyumlu:** tüm cihazlarda sorunsuz çalışır.

### Teknoloji yığını

- CSS3 (custom properties, Flexbox, transition — framework yok)
